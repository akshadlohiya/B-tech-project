  ⚠️ First: you need more ESP32s

  Every DW1000 needs its own ESP32. The DW1000 is only a radio. Something has to
  drive it over SPI, run the ranging code and handle timing. With 1 ESP32 you
  can build one working node, but ranging needs at least 2, and positioning
  needs 4:

  ┌─────────────────────────────┬───────┬───────────────────────────────────┐
  │            Role             │ Count │               Parts               │
  ├─────────────────────────────┼───────┼───────────────────────────────────┤
  │ Anchors (fixed, on walls)   │ 3     │ ESP32 + DW1000 each               │
  ├─────────────────────────────┼───────┼───────────────────────────────────┤
  │ Tag (the thing being        │ 1     │ ESP32 + DW1000                    │
  │ tracked)                    │       │                                   │
  ├─────────────────────────────┼───────┼───────────────────────────────────┤
  │ Server                      │ 1     │ Raspberry Pi (no radio wired to   │
  │                             │       │ it)                               │
  └─────────────────────────────┴───────┴───────────────────────────────────┘

  Buy 3 more ESP32 DevKit boards (any ESP32-WROOM-32 DevKit, about ₹350–450
  each). Also check:
  - Module form: a bare DWM1000 has tiny castellated pads. Jumper wires won't
    plug into it, so you need a breakout/adapter board or some soldering. If
    yours already has 2.54 mm header pins, you're fine.
  - Power: 4 USB cables plus phone chargers or power banks. The anchors only
    need power, not a computer.
  - Optional: 4 × 10 µF capacitors, a breadboard, and something to mount the
    anchors on.

  How it fits together

   [Anchor A1]  [Anchor A2]  [Anchor A3]      ← ESP32+DW1000, powered only
          \         |         /
           UWB radio ranging (DS-TWR)
                    |
                [Tag T1]  ESP32+DW1000       ← measures distance to each anchor
                    |
             Wi-Fi UDP, JSON per range → Pi:9000
                    |
   [Raspberry Pi]  gateway → solver/Kalman/AI → backend :3000 → viewer :5173

  In this design only the tag uses Wi-Fi. It ranges to each anchor and sends
  {"tag":"T1","anchor":"A1","range":..,"rxPower":..,"fpPower":..}, which is
  exactly the format the gateway already accepts. The anchors don't need Wi-Fi
  at all.

  Wiring (same for all 4 nodes)

  the #1 cause of "device not found". Put a 10 µF capacitor across VDD and GND
  close to the module, since the radio draws current in spikes.
